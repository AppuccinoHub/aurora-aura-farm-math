# Aurora's Aura Farm · Math

2nd-grade math practice with Aura the lamb: 2-digit addition and subtraction with and without regrouping.
Worksheet 1 matches the school's at-home practice sheet. "Help me" walks through base-ten blocks, break apart, an open number line, or stack it (regrouping).
One self-contained page (no network requests). Play: https://appuccinohub.github.io/aurora-aura-farm-math/
