# Aurora's Aura Farm · Math

2nd-grade math practice with Aura the lamb: add and subtract 2-digit and 3-digit numbers (within 1,000) with and without regrouping, and add three 2-digit numbers.
Worksheet 1 matches the school's at-home practice sheet. Worksheets 2 and 3 match the two "Adding 3 Two Digit Numbers" sheets.
"Help me" starts with 📦 Group it (expanded form: hundreds with hundreds, tens with tens, ones with ones, then put the groups back together, trading when needed), with a "make a ten first" tip.
She can switch to base-ten blocks, chunks (tens then ones), an open number line, or stack it (regrouping).
One self-contained page (no network requests). Play: https://appuccinohub.github.io/aurora-aura-farm-math/
